# How I Fall — сюжетная база

Source of truth: `HIF.holst`.

Источник канона: `HIF.holst`.

Эта папка заменяет старую сюжетную документацию как актуальная база по игре. Старые материалы теперь считаются legacy/черновиками и лежат в `docs/archive/old_story/`.

## Структура

- `game_concept.md` — базовый концепт игры.
- `characters/` — карточки персонажей.
- `world/locations.md` — локации и статус их проработки.
- `mechanics/` — игровые системы и переменные.
- `routes/route_overview.md` — обзор маршрутов.
- `references/art_style.md` — арт-стиль и визуальные ориентиры.
- `raw/holst_text_dump.md` — сырой текстовый дамп из доски.

## Правило канона

Если информация есть в Holst-доске и отсутствует в старой документации — приоритет у Holst.
Если старая документация конфликтует с Holst — старая документация уходит в архив.
Если в Holst есть только идея без деталей — фиксируем как `TODO`, не додумываем как факт.
