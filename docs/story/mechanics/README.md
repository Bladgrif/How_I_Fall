# Механики

Актуальные идеи из Holst:

- стартовые статы от бэкграунда Артёма;
- модификация статов образом жизни;
- дополнительные варианты диалога через статы;
- деньги, подработка, карманные деньги;
- подарки и влияние денег на выборы;
- демонические очки как ресурс искушения.

Подробная система ещё не зафиксирована. Все документы в этой папке — база для проектирования, не финальный баланс.
