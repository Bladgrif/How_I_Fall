# Алиса

## Роль

Ветеринарша, сильная и грубоватая девушка с тоской по равному партнёру.

## Краткое описание

Ветеринарша. Высокая, сильная. Водит Ниву, играет в стратегии. Хохотушка. Может вмазать, может выпить. Не терпит мямлей и манипуляторов.

За грубостью — тоска по романтике. Бывшие не выдерживали её силы. Хочет равного духом.

## Функция в игре

- маршрут силы и равенства;
- проверка героя на зрелость;
- отношения без игры в слабость;
- контраст между грубым поведением и романтической потребностью.
