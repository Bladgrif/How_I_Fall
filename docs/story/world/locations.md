# Локации

В Holst-доске есть отдельный блок `Локации`, но текстовых описаний локаций в извлечённом тексте нет. Большая часть информации по локациям, вероятно, находится в изображениях / визуальных референсах доски.

## Текущий статус

Нужна отдельная расшифровка локаций по изображениям или ручное описание.

## Базовые ожидаемые локации проекта

Эти пункты пока являются рабочими категориями, а не подтверждённым каноном из текста Holst:

- школа / школьный коридор;
- школьные ворота;
- класс / клубная комната;
- городские улицы;
- дом / квартира Артёма;
- места встреч героинь;
- мистические / иллюзорные пространства Вэл.
