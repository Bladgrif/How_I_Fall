# Current phase

**Polished Functional Demo First.**

## Приоритет

- работающий и стабильный функционал;
- удобный player-facing UX;
- аккуратный UI даже без финального арта;
- regression coverage;
- automated/runtime QA там, где это полезно;
- простая поддерживаемая архитектура;
- минимальные task-scoped изменения.

## Сейчас не является приоритетом

- написание и разработка сюжета;
- story routes;
- канонические story flags;
- финальный art;
- финальные backgrounds и characters;
- окончательный visual identity.

Сюжет будет подключён позже отдельным этапом после того, как пользователь предоставит актуальный сюжетный материал. Не следует делать предположений о будущем каноне.
