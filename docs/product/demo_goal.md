# Текущая фаза

**Polished Functional Demo First.**

## Приоритет

- стабильный работающий функционал;
- удобный player-facing UX;
- аккуратный UI даже без финального арта;
- регрессионное покрытие;
- автоматизированный/runtime QA там, где он полезен;
- простая поддерживаемая архитектура;
- минимальные изменения строго в рамках задачи.

## Сейчас не является приоритетом

- написание и разработка сюжета;
- сюжетные маршруты;
- канонические story flags;
- финальный арт;
- финальные фоны и персонажи;
- окончательная визуальная идентичность.

Сюжет подключается позже отдельным этапом после того, как пользователь предоставит актуальный материал. Не делать предположений о будущем каноне.
