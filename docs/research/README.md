## Правила

- Не собирать десятки ссылок без выводов.
- Сохранять несколько сильных источников и конкретные выводы.
- Отличать проверяемые факты от вкусового решения.
- Для актуальных инструментов, Unity и API проверять свежие источники.
- Исследование само по себе не разрешает менять проект.
- Реализация начинается только после принятого решения.
- Человеко-читаемый текст исследования ведётся по-русски; технические идентификаторы и названия источников сохраняются точно.
