# Research

Папка содержит существенные и повторно используемые исследования, которые помогают принимать решения для How I Fall.

Research-документ создаётся только для заметного вопроса, к которому нужно будет возвращаться. Мелкая очевидная задача не требует отдельного research-файла.

## Правила

- Не собирать десятки ссылок без выводов.
- Сохранять несколько сильных источников и конкретные выводы.
- Отличать factual evidence от вкусового решения.
- Для актуальных инструментов, Unity и API проверять свежие источники.
- Research сам по себе не разрешает менять проект.
- Implementation начинается только после принятого решения.
