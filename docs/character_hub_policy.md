# Политика Character Hub / биографий

> **Статус:** техническая основа реализована; обычный player-facing launcher сейчас скрыт/отложен. Реальные персонажи, биографии, портреты и правила открытия относятся к будущему сюжетному этапу.

## Граница

Character Hub существует только как технический фундамент. TEST-данные не являются каноном.

Технические fixtures:

- `TEST CHARACTER A` — видимый профиль;
- `TEST CHARACTER B` — закрытый профиль.

Не определяются будущие канонические персонажи, отношения, ранги, пороги Friend/Love/Hate или глобальная система unlock-флагов.

## Данные профиля

Статический профиль хранится в `CharacterProfileDefinition : ScriptableObject` и содержит стабильный `characterId`, отображаемое имя, портрет и биографию. Эти данные read-only в runtime и не копируются в `GameState` или `SaveData`.

ID обязаны быть непустыми и уникальными. Ошибочная конфигурация должна fail-closed и выдавать диагностику.

## Технический мост отношений

Текущие `trustMasha`, `trustArtem`, `leraInterest` могут читаться через закрытый typed enum/resolver. Reflection, строковые имена полей, `Dictionary`-доступ и произвольные выражения запрещены.

Этот мост не задаёт будущую архитектуру отношений.

## Modal-контракт

Character Hub — обычная scene-local modal surface, а не новый `SpecialMode` и не новый manager.

Пока Hub открыт:

- dialogue advance заблокирован;
- Auto/Skip приостановлены и после закрытия возвращаются только по обычным eligibility-правилам;
- `Esc` закрывает Hub без продвижения диалога;
- `GameState` не изменяется;
- Hub не может открываться поверх Settings, History, Save/Load, подтверждений, Replay, Hide UI или `BlockingExclusive` special mode.

Открытое состояние transient и не сериализуется. `SaveData.CurrentVersion` остаётся `3`.

## Текущий продуктовый статус

Техническая foundation считается `DONE`, но обычный player-facing вход намеренно скрыт в текущей фазе **Polished Functional Demo First**. Возвращать Hub в обычный интерфейс следует только вместе с реальным сюжетным/персонажным материалом и отдельным UX-решением.
