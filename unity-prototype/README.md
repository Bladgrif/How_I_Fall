# Unity Prototype

Экспериментальный Unity-прототип для How I Fall.

Цель:

- проверить, подходит ли Unity для How I Fall
- протестировать живые фоны, 2.5D-композицию, textbox, выборы и простую интерактивность
- не заменять текущий Ren'Py-проект до отдельного решения

Текущий Ren'Py-проект остаётся в папке `game/`.

План первого прототипа:

1. сцена школьного коридора или комнаты ночью
2. один фон
3. один персонаж
4. textbox
5. несколько реплик
6. один выбор
7. простая анимация света или камеры
